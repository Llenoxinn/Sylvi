# Sylvi mascot candidates

Six independent character images for Sylvi, an automated photo-printing app serving Filipino print shops. The name comes from Tagalog **silbi**, usefulness / being of service. The intended personality is helpful, reliable, and friendly.

All six originals are **1254 × 1254 PNGs**, preserved byte-for-byte at the native size returned by the generator. Each candidate was generated once. No references, retries, filtering, post-processing, or resampling were used.
