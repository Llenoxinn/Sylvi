# Sylvi: variations of original A1

Six variations of the selected [original A1 carabao](../A1-carabao-lower-left.png). The same original was the only visual reference for every candidate.

The palette stays consistent: **golden mango #F6BD60** for the head and body, **deep mulberry #8E235D** for the horn crown and facial marks, and **muted jade #AACABB** for the background. These are the intended prompt colors rather than measurements of generated pixels.

Labels A1–C2 in this folder belong to this new batch; the selected original A1 remains in the parent folder.

All images were preserved as returned, without resampling or post-processing. The generator returned native **1254 × 1254** files for the requested approximately **1536 × 1536** square canvas. Each candidate was generated once; every returned result is included.

- Constraint delivery: **main-prompt constraints**, included verbatim in every recorded prompt.
- Method: six independent calls, each using only the original A1 as reference, executed by three parallel workers.
